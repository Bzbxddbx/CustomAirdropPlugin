# CustomAirdropPlugin

Плагин для Paper (1.20.4–1.21+) с системой кастомных аирдропов: случайная безопасная точка на карте, появление «Мистического сундука», голограмма-табличка над ним и лутание при клике.

## Возможности

- **Как работает**: команда `/airdropstart` запускает событие — сервер находит безопасную точку и спавнит сундук с голограммой. Игрок кликает ПКМ по сундуку, пока тот в статусе `ACTIVE`, — он открывается с частицами и звуком, а голограмма меняется на «ОТКРЫТ».
- **Тексты** — только Adventure `Component`, никакого устаревшего `ChatColor`.
- **Голограмма** — нативный `TextDisplay` из Paper API, без сторонних библиотек.
- **Поиск локации** — строго асинхронный (`CompletableFuture.supplyAsync`), основной поток не блокируется.
- **Конфигурация** — настройки и лут хардкодятся в `ConfigSettings` (бета-версия, без парсеров), архитектура готова к подключению БД/конфигов.

## Стек

- Java 25 (современные фичи: `record`, pattern matching, `var`, `List.getFirst()`)
- Paper API 1.20.4–1.21+ (нативно `TextDisplay`, Adventure, `Bukkit.getScheduler().getMainThreadExecutor`)
- Maven
- Без сторонних библиотек для голограмм/приватов

## Архитектура

```
api/          — контракты плагина
  Airdrop             — интерфейс аирдропа (id, локация, состояние, spawn/open/remove)
  AirdropManager      — управление событием (start/stop/getActive)
  location/LocationSearcher — асинхронный поиск безопасной точки
core/         — доменная модель
  ActiveAirdrop       — реализация Airdrop: CHEST + TextDisplay, лутание, частицы
  AirdropState        — enum: WAITING, SPAWNING, ACTIVE, OPENED
manager/      — EventManager: оркестрация события (main-thread continuation)
listener/     — PlayerInteractListener: ПКМ-перехват по сундуку
config/       — ConfigSettings: record-константы (радиус, лут, сообщения)
command/      — регистрация /airdropstart
util/, core/loot/ — заготовки под дальнейшую логику (лут, пакеты)
```

### Ключевые решения

- `EventManager implements AirdropManager, LocationSearcher` — наследует дефолтную асинхронную реализацию поиска без лишних классов.
- Продолжение асинхронной цепочки — на главном потоке через `getMainThreadExecutor(plugin)`: любая работа с миром безопасна.
- Статусная машина предотвращает повторное открытие: при `OPENED` клик отдаётся ванильному сундуку.
- Развязка через интерфейсы (`api`) — замена `EventManager`, источника лута или поиска локации не требует трогать слушатели и команды.

## Использование

Сборка:

```
mvn clean package
```

Полученный jar из `target/` положить в папку `plugins` сервера и перезапустить.

Команды:

| Команда        | Описание           |
|----------------|--------------------|
| `/airdropstart`| Запустить событие  |

## Статус

Бета: без БД и файловых конфигов, лут задан константами в `ConfigSettings`. Архитектура готова к интеграции хранилища и парсера конфигурации.
